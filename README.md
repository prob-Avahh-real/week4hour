# Week4Hour (4-Hour Week)

A lifestyle design app based on Tim Ferriss's "The 4-Hour Workweek" DEAL framework: Definition, Elimination, Automation, Liberation.

## Features
- DEAL framework guided workflow (D-E-A-L phases)
- Weekly time audit with Pareto analysis
- Elimination rules (information fast, batch processing, etc.)
- Automation builder templates
- Dreamline calculator (passive income goals)
- Fear-setting exercise for decision making
- Progress tracking across all phases

## Architecture
- MVVM pattern with DEALViewModel
- All models in DEALModels.swift
- Dark mode default UI

## Requirements
- iOS 17.0+
- Xcode 15.0+

## DEAL Framework
1. **Definition**: Define your ideal lifestyle
2. **Elimination**: Cut 80% low-value activities
3. **Automation**: Build income automation systems
4. **Liberation**: Achieve location independence
